=== Nikon Institute ===
Bilingual (English / Arabic) WordPress theme for the NIKON Institute.

== Installation ==
1. Appearance > Themes > Add New > Upload Theme, choose nikon-institute.zip, Install, Activate.
2. On activation the theme imports everything automatically:
   - 44 English pages + 44 Arabic pages (Arabic lives under /ar/), with section tabs
   - 3 news posts in each language
   - all images into the Media Library
   - "Primary (English)" and "Primary (Arabic)" menus, assigned to their locations
   - the English Home page as the front page, and pretty permalinks
3. Appearance > Nikon Institute: set the email that receives form submissions
   (default info@nikoninstitute.org) or re-run the import.

== Forms ==
Contact (Enquiry) and the four Partnerships pages use [ni_form type="..."].
Types: contact, strategic, institutional, devPartners, joinUs.
Every submission is emailed and saved under "Form submissions" in the admin.
Tip: install an SMTP plugin (e.g. WP Mail SMTP) so email delivery is reliable.

== Languages ==
Each page knows its translation, so the English / العربية switch in the top bar
and footer opens the same page in the other language. Arabic pages render RTL.

== Editing ==
Inner pages are normal WordPress pages (Custom HTML blocks keep the design).
News: Posts > Add New and pick English or Arabic in the "Language" box.
The News pages list them automatically with [ni_news].
